# SetRoom

SetRoom is a browser-first collection workspace for LEGO display builders.

## Included

- Free collection catalogue with owned, wanted and sold states
- Shelf measurements, fit checking, rotation and automatic arrangement
- Build timer, progress history and local camera replay recording
- Selling calculator, take-home profit tracking and listing draft
- Buying recommendations based on budget, themes and available display space
- Local browser persistence plus JSON export/import
- Responsive desktop and mobile interface

## Commercial launch checklist

The demo presents SetRoom Pro at £29/year, but payments and account entitlements are not connected in this static release. Before charging customers, connect a checkout provider, validate access server-side, add production support/contact details, and confirm permission for every external image or data source used commercially.

The £500 dashboard target is a planning goal, not a profit guarantee.
