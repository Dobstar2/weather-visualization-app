Is SetRoom an official LEGO product?

No. SetRoom is an independent, unofficial fan-made collector tool. LEGO and related marks belong to the LEGO Group.

Are prices and dimensions guaranteed?

No. The built-in catalogue is planning data. Confirm dimensions, contents and current prices from the box or retailer before buying, building or selling.

Where is collection data stored?

This static release stores data locally in the browser. Export a backup before clearing site data or changing devices. A commercial version should add accounts and cloud sync.

Can a GitHub Pages paywall be secure?

Not by itself. The included product experience has a checkout hook and local trial. Real entitlement enforcement needs a payment provider plus a small backend or licence service.
